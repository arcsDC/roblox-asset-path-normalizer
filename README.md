# roblox-asset-path-normalizer

A Roblox Studio plugin that normalizes and validates asset paths for consistent data-driven development.

## Stack

Primary language: **Luau**

## Project structure

- `plugin/AssetPathNormalizer.lua` — Standardizes asset path formats and detects invalid references in Studio.
- `plugin/init.lua` — Plugin entry point

## Usage

Review the source files and install any dependencies referenced by the project before running it.
